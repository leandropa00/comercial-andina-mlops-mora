# Comercial Andina · MLOps para predicción de mora

Proyecto académico — Caso C, Unidad 3, Universidad de Caldas.

**Autores:** Mateo Aguirre, Santiago García y Leandro Panesso Atehortúa.

> Datos sintéticos reproducibles; no representan clientes reales. El modelo es un ejercicio de aprendizaje y no debe usarse para aprobar créditos, restringir cupos ni adoptar decisiones automatizadas sobre personas.

La documentación, experimentos, pruebas y API se incorporan en este repositorio con las evidencias del taller.
